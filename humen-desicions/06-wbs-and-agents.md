# WBS 与 Agent 分工表

> 配套文件：`04-course-workflow.md`（七阶段流程）、`05-resource-plan.md`（已批准的资源配置）。
> 本文把流程拆成可验收的工作包，并规定每个 Agent 的输入、输出、权限与失败处理。

## 0. Agent 角色定义

| 代号 | 角色 | 驱动 | 成本 | 只做什么 | 绝不做什么 |
|---|---|---|---|---|---|
| **C** | 协调 Agent | 我（DeepSeek V4.1 Flash / OpenCode） | 上下文 | 拆解、写规格、验收、合并、对外沟通 | 不做大段内容生产；不做视觉判断；不重复跑已绿的测试 |
| **D** | 确定性 Worker | shell / pytest / WeasyPrint / ffmpeg | 免费 | 构建、测试、门禁、渲染、截图、跑分 | 不做语义判断；不改教材内容 |
| **F** | 插图 Agent | 本地 Python + arkcli Lite | 12 张额度 | 生成矢量/混合插图、出门禁产物 | 不写书稿；不调用 Pro |
| **S** | 学生 Agent | CodeBuddy `hy3 --effort low` | 8 次 | PDF-only 完成任务并如实报告 | 不读审计/章节源；不 commit；不联网 |
| **R** | 复核 Agent | hy4free | 低 | 逐字读图、返回可见字符串 | 不做事实源；不判对错 |
| **O** | 运维 Agent | C + `ssh` + `docker compose` | 免费 | 部署、备份、冒烟、回滚 | 不改仓库内容；不打印密钥 |
| **H** | 人类 | 你 | 注意力 | 两次决策：本方案 + 终审 | —— |

**协作铁律**

1. 任何跨 Agent 产物必须落在约定路径，口头结论不算交付。
2. S 与 R 的结论必须由 C/D 独立复跑或对账，不直接采信。
3. F 与 D 失败时回退到“改输入重跑”，不允许用 `--force` 掩盖。
4. O 的任何变更必须先备份；失败即回滚，不现场调试。

## 3. Agent 接口契约

### S · 学生 Agent

- **输入**：PDF 副本（`/tmp/opencode/student-pdf/`）、任务书、干净 worktree。
- **输出**：Markdown 报告（命令/期望/实际/卡点/置信度）+ 改动后的 worktree。
- **约束**：`--add-dir` 只授权 PDF 目录；`--max-turns 40`；不 commit。
- **失败**：报告写“做不到”并给卡点，不允许编造输出。

### R · 复核 Agent

- **输入**：PNG + 文本清单。
- **输出**：逐行可见字符串；读不到图输出 `NO_VISION`。
- **约束**：只转写，不评价。
- **失败**：空输出或 `NO_VISION` 视为未复核，不得记为通过。

### F · 插图 Agent

- **输入**：content JSON（事实、文案、类比）。
- **输出**：SVG/PNG/layout/manifest/checks。
- **约束**：先 `--dry-run`；Lite 一张一次；文字必须外置。
- **失败**：门禁失败只改 JSON/文案，不重试碰运气。

### D · 确定性 Worker

- **输入**：命令或测试目标。
- **输出**：stdout/退出码/产物文件。
- **约束**：不允许“看起来通过”；必须保留原始输出。
- **失败**：原样贴错误，不静默降级。

### O · 运维 Agent

- **输入**：部署计划 + 备份点。
- **输出**：容器状态、health、冒烟证据。
- **约束**：不打印密钥；变更前必备份。
- **失败**：立即回滚，不在线上调试。
