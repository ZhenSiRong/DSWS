## 二、拆法（全部是结构标记，无一处改字）

1. **`>` 前置引用行**（p15/p19/p20/p23）：按 `。`/`；` 拆成多行 `> `，段间插入 `>` 空引用行；首段保留「前置：…」领词。
2. **长 bullet**：保留首句（多为粗体领句）作 bullet，其余句子改为**缩进子项** `    - …`。缩进用 4 空格：`python-markdown` 只认 4 空格为子列表（2 空格会渲染成同级列表），仓库既有页面（如 p01/p03）同惯例；已核对渲染后的 `<ul>` 正确嵌套。
3. **长编号步骤**：步骤标题留在编号行，其余枚举句改为缩进子项（p10 拆一刀 3、p15 拆一刀 1、p16 拆一刀 1）。
4. **长散文段**（p18 一处）：按句号拆成空行分段。
5. 断行点一律避开**行内 code / 粗体 / 链接** span 内部（脚本按受保护 span 切分；`**` 不拆开），因此判据粗体句、行内代码原样保留。
