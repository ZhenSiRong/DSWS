## 8 类必查清单（逐条打勾再交）
逐类在行尾补「→ 结论：通过 + 一条证据 / 不适用 + 原因 / 未过 + 问题清单行号」，全通过也要写；坑的成因与修法先查 [TRAPS](../TRAPS.md)。
- [ ] **uv.lock 改写**：跑过 `uv run` / `make stage*` 就看 `git diff backend/uv.lock`；lab 白名单不含它、reset 救不回，脏了 `git checkout --` 还原。
- [ ] **cwd 子 shell**：命令块的 `cd backend &&` 要放进 `( … )` 或随后 `cd ..`；每步后 `pwd` 应回仓库根，否则后续命令全 127。
- [ ] **管道退出码**：`命令 | tail` 的 `$?` 是 tail 的 0，判据退出码看 `${PIPESTATUS[0]}`，别把红判据记成绿。
- [ ] **端口与 `.env`**：宿主机默认端口被占只改 `.env` 的 `*_HOST_PORT`、不改 `compose.yaml`；`curl` 端口与 `.env` 一致，别照抄默认 8080。
- [ ] **lab 快照边界（DB、uv.lock）**：`lab save` 只覆盖白名单，数据库状态和 `uv.lock` 都不在快照里，「完全一致」只承诺白名单内文件。
- [ ] **重录假绿**：按提示重录夹具（`record_sse` 等）会用坏代码覆盖夹具、`--check` 反而变绿；还原只用 `lab reset`，不重录。
- [ ] **精确行号与同名代码**：动手位置给「文件:行号」；同名函数/同一行可能多处出现，先全仓搜再改，别全局替换。
- [ ] **跨页前置回绿**：开页前确认上一页「拆一刀」已 reset；未回绿会红在本页判据上，先 reset 再判。
