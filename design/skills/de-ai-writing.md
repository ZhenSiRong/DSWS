# 去 AI 味写作规则（项目内）

来源：`humanizer` v3.1（MIT，https://github.com/blader/humanizer）的结构规则，加上中文技术文档里常见的 AI 腔清单。只取规则，不安装第三方仓库。

## 三条底线

1. **事实不能动。** 数字、表名、列名、错误码、命令、路径、结论、证据标记，全部保持原样。改写只动说法，不动内容。
2. **每句话都要带来新信息。** 不重复上一段，不解释读者刚看过的例子，不用一句话总结刚说完的话。
3. **人写的东西不均匀。** 句子有长有短，段落有轻有重。允许具体例子、插入语、判断和边界说明；不追求每段一样整齐。

## 硬边界

- 不改：代码块、行内代码、命令、路径、URL、YAML/JSON、表名、列名、错误码、计数、图号、表号、图片路径、证据标记（✅ / 🟡 / ⚪）。
- 不改事实、结论、边界、未验证状态；不新增事实、数字、引用、承诺。
- 不删安全警告、前置条件、失败说明、回滚步骤。
- 表格保留。表格里只有明显是套话的句子才改，单元格里的标识符和数字不动。
- 操作步骤里的「首先 / 其次 / 最后」可以保留；叙述段落里的机械路标要删。
- 标题层级、章节顺序、锚点链接不动，除非原结构本身有错。

## 中文 AI 腔清单

### 1. 伪深刻的开场和总结

看到就删，或者换成具体事实：

- 值得注意的是 / 需要指出的是 / 值得一提的是
- 总的来说 / 综上所述 / 由此可见
- 从某种意义上说 / 在一定程度上
- 本质上 / 核心在于 / 关键在于
- 换句话说 / 也就是说（除非真的在换一种说法解释难点）
- 这不仅是一次……更是一次……
- 这不仅是……而是……
- 为……提供了有力支撑 / 奠定了坚实基础
- 形成了……闭环 / 构建了……体系 / 打通了……链路
- 在……背景下 / 随着……的不断发展

改写方向：把「意义」换成「发生了什么」。

- 原句：值得注意的是，S2 的写入是幂等的。
- 改写：S2 的写入是幂等的。重复跑一次，第二次输出 `NOOP: 0 writes`。

- 原句：综上所述，S0–S7 已经形成完整闭环。
- 改写：S0–S7 都能单独验收。S8 还没做。

### 2. 「不是 X，而是 Y」

这是中文 AI 文本里最密的句式。它先立一个没人相信的靶子，再抬高后半句。除非 X 是读者真的会误解的说法，否则直接说 Y。

- 原句：S0 要消灭的不是「SQL 写得对不对」，而是「前后端能不能对同一件事达成一致」。
- 改写：S0 只保证一件事：前后端对同一件事的说法一致。SQL 写得对不对，要到 S4 才管。

- 原句：这不是巧合，而是刻意的可复现设计。
- 改写：这是刻意的：能离线判定的东西，就不要绑在 Docker 上。

- 原句：它不是功能清单的继续，而是把前面散落的约束收成一条流水线。
- 改写：这一章把前面散落的约束收成一条流水线，不再按功能罗列。

### 3. 机械路标和排比

- 首先 / 其次 / 再次 / 最后（叙述段落里连续出现时）
- 一方面……另一方面……
- 既……又……；不仅……而且……；不但……还……
- 第一、第二、第三，但三项之间没有真正的并列关系

改写方向：让内容自己过渡。该分点就分点，该用段落就用段落；三项里只有两项有实质内容，就写两项。

### 4. 空泛的动词和形容词

少用：赋能、抓手、沉淀、打通、闭环、对齐、拉通、落地、升级、优化、提升、显著、极大地、进一步、全面、系统性、深度、真正、恰恰、正是。

这些词可以用。每次出现都问一句：换成具体动作或数字，句子会不会更清楚？

- 原句：进一步提升了召回质量。
- 改写：20 题黄金集里，Top-5 命中从 16 题提高到 19 题。

（没有真实数字就不要编。没有数字就写清楚改了什么机制。）

### 5. 每段结尾的金句

AI 喜欢在段落最后补一句「这才是关键」「这一点很重要」「这就是区别」。如果这句话没有新事实，删掉，让段落停在具体结论上。

### 6. 装饰性格式

- 不要给每个列表项加粗体标签再加冒号；标签没有独立信息时，改成普通段落。
- 不要用 emoji 做装饰。项目里的 ✅ / 🟡 / ⚪ 是证据标记，保留。
- 不要每节之间加水平分割线；标题已经分隔了内容。
- 不要用「让我们」「接下来我们」这类导游句，直接进入内容。

### 7. 重复解释

- 标题下面第一句不要重复标题。
- 例子讲完不要再补一句「这个例子说明……」；读者看得出来。
- 同一个结论不要在一节的开头、中间、结尾各说一遍。

## 改写方法

1. 先通读整节，标出套话、重复、伪深刻句、机械路标。
2. 按段落重写，不要逐词替换。先确定这一段要说的唯一一件事，再用自己的话写。
3. 保留所有代码、表格、数字、链接和证据标记。
4. 读一遍。问自己：这句话是不是只有人类会写？删掉它，信息有没有损失？有损失就留，没损失就删。
5. 再搜一遍高频词：不是、而是、值得注意、综上、本质、核心、闭环、真正、进一步、显著、从而、使得、此外、然而、因此。

## 自检

- 代码块数量、命令、路径、表名、列名、错误码、计数与改写前一致。
- 没有新增事实、数字、引用或承诺。
- 没有把 🟡 写成 ✅，没有把 ⚪ 删掉。
- 每个段落都能回答「这段新增了什么信息」。
- 连续三段没有相同的开头句式。
- 读起来像一个人在讲这件事，不像在填模板。
