# 03 · 编辑杂志 · 设计说明

**概念**：把设计图集做成一本有观点的杂志。深蓝封面 + 白色衬线大标题 + 巨大 `05—08` 背景数字；正文用窄栏衬线、宽右页边、深色表头和主题色标签，章节 opener 有整页换气。

**字体与网格**
- 正文 `Noto Serif CJK SC` 9.9pt / 1.68；标题同族 900，h1 38–44pt、h2 20pt；h3 用 `Noto Sans CJK SC` 700。
- A4；上/下 20mm、左/右 18mm；正文约 62% 宽，右侧留白给图注/拉引。
- 章节号 `05` / `06` 用大号衬线，主题色。

**色板**
- 纸 #FFFDF8；墨 #111；S5 钴蓝 #1F4E9C、S6 锈红 #B24A2E、S7 森林绿 #2F5D46、S8 芥末 #C58B1B。
- 表格深色表头 + 浅 tint；代码块深墨 #151515 + 米色字。

**封面**
- 满版深钴蓝；白色衬线 `DSWS` / `从零到一`；琥珀短线；巨大 `05—08` 背景；右下角图形。
- 目录为杂志 Contents 式，部分用主题色数字。

**做了什么**
- 重写 `book.css`：窄栏、衬线标题、深色表头、拉引、章节 opener。
- 重写 `cover_html()`：深蓝封面、巨大数字、图形块。
- 控制 opener 只用于 h1/部分，不给每个 h2 强制换页（避免半空页）。

**已知限制**
- 67 页，比基线样张多 13 页；章节 opener 和窄栏增加了页数。
- 正文右页边大部分留白，信息密度偏低；适合图集/评审，不适合查阅手册。
- 表 3-1 在窄栏里偏小，打印可读，屏幕需放大。

**与另外 5 套的差异**
- 唯一的“杂志封面 + 巨大期号 + 深色表头”语言；最有视觉记忆点。

**图标**：Lucide inline SVG（circle-check / circle-alert / circle-help），3.2mm，颜色按本套色板；`vertical-align: -0.15em` 与正文基线对齐。

**验证集（2026-11-03）**：在 4 个空白页插入 4 张解释性图——p4「一次问数，五道关」、p16「四道交接：每一站都要交出一个判据」、p43「三层单向依赖」、p56「六服务启动链」。图源在 `03-editorial/design/assets/figs/`，由 `make_figs.py` 生成；图宽 1600×1100，按 03 的 cobalt/rust/forest/mustard 色板绘制，图注在正文栏。验证用的 PDF 仍是 `dsws-style-03-editorial.pdf`（67 页）。
