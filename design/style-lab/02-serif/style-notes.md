# 02 · 学术衬线 · 设计说明

**概念**：一本可以连读一小时的教材。正文用衬线、暖纸色和宽外侧页边，让设计退到论证后面；封面用双线框和 oxblood 强调，保留“书”的分量。

**字体与网格**
- 正文 `Noto Serif CJK SC` 10.4pt / 1.78 / #1A1A1A；标题 `Noto Sans CJK SC` 600，h1 22pt、h2 14pt、h3 11pt。
- A4，上/下 24mm；左 24mm、右 28mm；正文约 158mm；右侧页边放短边注。
- h1 下方 0.8pt oxblood 细线；页眉小型大写，页码居中。

**色板**
- 纸 #FBF9F4；墨 #1A1A1A；次级 #6B6259；线 #D8D0C4；强调 #7A2E2E。
- 表格是书tab 风格：顶/底 1pt、表头下 0.6pt，无竖线、无斑马纹。
- 代码暖灰 #F4F0E8、深褐字、左侧 oxblood 竖线。

**封面**
- 暖白纸，双线框（外 1pt / 内 0.4pt），内缩 12mm；`D S W S` 字距拉开，`从零到一` 36pt 衬线；副标题 12pt；底部基线信息。
- 目录衬线、点线、页码右对齐。

**做了什么**
- 重写 `book.css`：衬线正文、标题、书tab 表格、暖色代码块、边注样式、页眉页脚。
- 重写 `cover_html()`：双线框、字距标题、副标题、底部信息。
- 调整目录与章首页留白。

**已知限制**
- 61 页，比基线样张多 7 页；边注和章首留白增加了页数。
- 右侧边注目前只承载小标题/定义提示，信息量有限；正式铺到全书时可改为真正的旁注。
- 衬线中文在 10.4pt 下密度较高，打印没问题，手机屏阅读偏重。

**与另外 5 套的差异**
- 唯一的暖纸色 + 衬线正文 + 双线框封面；最像传统教材/学术专著。

**图标**：Lucide inline SVG（circle-check / circle-alert / circle-help），3.2mm，颜色按本套色板；`vertical-align: -0.15em` 与正文基线对齐。
