# 06 · 终端开发者志 · 设计说明

**概念**：一本给终端里长大的人看的开发者志。封面是终端窗口，正文用等宽标题、`[05]` 章节号、绿色提示符和琥珀命令；代码/图用深色终端窗包住，正文保持浅色。

**字体与网格**
- 正文 `Noto Sans CJK SC` 9.4pt / 1.65；标题 `Noto Sans Mono CJK SC` 700，h1 22pt、h2 13pt。
- A4；上/下 18mm、左/右 18mm；左上有 `user@dsws:~/book` 小条。
- 章节号 `[05]` / `[06]` 等宽绿色；页脚 `exit 0`。

**色板**
- 纸 #F5F5F0；墨 #1B1F24；深色岛 #0E1116；绿 #00A86B；琥珀 #D97706；灰 #6B7280。
- 表格等宽表头 + 深色表头底；代码深色 + 绿色提示符；图套终端窗口外框。

**封面**
- 深色 #0E1116 满版；顶部 `user@dsws:~$`；主标题 40pt 等宽白；琥珀 `./read --part S5..S8`；终端输出块 + 绿色光标。
- 目录为 `$ cat CONTENTS` 式等宽列表。

**做了什么**
- 重写 `book.css`：等宽标题、终端窗口、深色代码/表格、页眉页脚。
- 重写 `cover_html()`：终端窗口封面、提示符、输出块。
- 图统一套终端窗框，图内容不变。

**已知限制**
- 51 页，最紧凑；深色代码块/终端窗在打印时费墨。
- 等宽标题 + 终端梗对非技术读者门槛高。
- 图框标题栏会压缩图的可用宽度。

**与另外 5 套的差异**
- 唯一的“终端窗口 + 等宽标题 + 绿/琥珀”语言；最开发者向。

**图标**：Lucide inline SVG（circle-check / circle-alert / circle-help），3.2mm，颜色按本套色板；`vertical-align: -0.15em` 与正文基线对齐。
