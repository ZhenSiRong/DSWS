# 风格 05 · 工程蓝图（Blueprint）

先读 `design/style-lab/BRIEF.md`，再执行本文件。目标：**把书当成一套工程图纸**。图纸标题栏、网格纸、等宽标注、蓝色细线、橙色标记、图号/坐标；正文页白底细边框，网格只出现在封面和章节 opener。

## 视觉规则

- 网格：A4；上/下 18mm；左/右 16mm；正文页四边 0.4pt 蓝框，右上角小标题栏；封面/章 opener 用 0.2pt #DCE8F5、10mm 间距网格。
- 字体：正文 `Noto Sans CJK SC` 9.2pt / 1.68 / #10233F；标题 `Noto Sans Mono CJK SC` 700，h1 24pt、h2 13pt、h3 10.5pt；章节号 `[05]`/`[06]`，**编号必须与章节对应，不要用自增页码**；标注 7.8pt 等宽 #2F6FB0。
- 色板：纸 #F7FBFF；墨 #10233F；蓝 #0B3D91；辅助蓝 #2F6FB0；橙 #F28C28；线 #B8D0E8。
- 表格：标题栏式表头（浅蓝底蓝字或蓝底白字），0.4pt 网格，数字列等宽右对齐。
- 代码：白底、蓝色 1pt 左边框、等宽 7.9pt；左上角 `CODE` 小标签。
- 引用：`NOTE` / `WARNING` 小标签 + 蓝/橙 0.8pt 边框；无圆角。
- 封面：白底 + 蓝图网格；外框 1pt、内框 0.4pt；右下角图纸标题栏（项目/图号/比例/日期）；主标题 40pt 等宽/黑体、橙色 1.5pt 线；中间放一张 SVG 线框/局部，不要重画。
- 目录：`SHEET / TITLE / PAGE` 表格；等宽 7.8pt；h1 条目加粗、浅蓝底；标题 `DRAWING INDEX / 目录`。
- 图/表：图加 0.4pt 蓝框 + 四角标记；图注等宽、`FIG. 07`；表题 `TABLE 3-1`；允许横线、不要竖线满格。

## 验收

- 章节编号必须正确（S5 是 `[05]`，不是 `[11]`）；正文页不要满屏网格。
- PDF 40–90 页；`style-notes.md` + 两张预览 PNG。
- 不要改章节内容；构建用 `design/style-lab/.venv`。
