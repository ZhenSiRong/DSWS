# 风格 04 · 日式留白（Japanese Minimal）

先读 `design/style-lab/BRIEF.md`，再执行本文件。目标：**安静、精确、几乎全是空气**。小字号、窄栏、极大留白、0.3pt 细线、墨色 + 一点茜色或靛蓝；不要热闹、彩色底纹、大黑块。

## 视觉规则

- 网格：A4；上/下 30mm；左/右 28mm；正文窄栏约 130–140mm（每行 34–38 汉字）；行高 1.95。
- 字体：正文 `Noto Serif CJK SC` 9.4pt / 1.95 / #1C1C1C；标题 `Noto Sans CJK SC` 300/400，h1 18pt 字距 0.12em、h2 12.5pt、h3 10.5pt；不要粗黑标题。
- 色板：纸 #FAFAF7；墨 #1C1C1C；次级 #6F6A62；线 #D8D4CC（0.3pt）；强调靛蓝 #223A5E 或茜色 #B03A2E（二选一，全书只用一种）。
- 表格：无底色/竖线；顶/底 0.4pt、行 0.25pt；表头 7.8pt 灰；padding 3mm；**第一列至少 22mm，不能让“S5 安全边界”竖排**；表格可以窄于版心，但必须可读。
- 代码：纸色 #F3F1EC、深墨字、0.3pt 细框；7.8pt；不要深色底。
- 引用：不画框；左侧缩进 5mm + 0.3pt 竖线；标签 7.5pt 字距 0.1em。
- 封面：几乎空白；暖白纸；右上/左上小标题块；标题 26–30pt 衬线、字距 0.08em；0.3pt 竖/横线 30mm；副标题 9pt；底部 baseline/date 7.5pt。不要图片、大色块。
- 目录：大量留白；条目 8.5pt、行距 2.2、点线 0.2pt；标题 16pt 字距 0.2em。
- 图/表：图小、居中、版心 75–85%；图注 7.8pt 灰；表 7.8pt；宁可换页也不要挤压。

## 验收

- 表格不挤压、不竖排；连续读不觉得“空得慌”。
- PDF 40–90 页；`style-notes.md` + 两张预览 PNG。
- 不要改章节内容；构建用 `design/style-lab/.venv`。
