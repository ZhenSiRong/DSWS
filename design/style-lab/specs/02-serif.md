# 风格 02 · 学术衬线（Academic Serif / OSTEP）

先读 `design/style-lab/BRIEF.md`，再执行本文件。目标：**一本可以连读一小时的教材**。正文衬线、暖纸色、宽外侧页边、书tab 风格表格、短边注；设计退到论证后面，封面要有分量。

## 视觉规则

- 网格：A4；上/下 24mm；左 24mm、右 28mm（外侧留宽放边注）；正文单栏约 158mm；行高 1.78。
- 字体：正文 `Noto Serif CJK SC` 10.4pt / 1.78 / #1A1A1A；标题 `Noto Sans CJK SC` 600，h1 22pt、h2 14pt、h3 11pt；h1 下 0.8pt oxblood 细线。
- 色板：纸 #FBF9F4；墨 #1A1A1A；次级 #6B6259；线 #D8D0C4；强调 #7A2E2E。
- 表格：书tab 风格——顶/底 1pt、表头下 0.6pt、无竖线/斑马纹；表头 8.2pt 小型大写；数字右对齐。
- 代码：暖灰 #F4F0E8、深褐字 #2B2118、左侧 0.8pt oxblood 线；8pt；不要深色底。
- 引用：左侧 2pt oxblood 竖线、斜体衬线、无底色；标签小型大写。
- 边注：右侧页边 8pt #8A8175，只给关键定义/反例，不要每页都有。
- 封面：暖白纸、双线框（外 1pt/内 0.4pt #7A2E2E，内缩 12mm）；标题 `Noto Serif CJK SC` 700 36pt；副标题 12pt；24mm oxblood 短线；底部 baseline/date。不要图片、不要深色块。
- 目录：衬线、点线 0.3pt、页码右对齐；h1 条目小型大写；标题 26pt。
- 图/表：图居中、宽度 ≤ 版心 90%、图注 8.5pt 衬线；表题 8.5pt 衬线粗体。

## 验收

- 连续读 10 分钟不累；表格不能有竖线压迫感；边注不能遮挡正文。
- PDF 40–90 页；`style-notes.md` + 两张预览 PNG。
- 不要改章节内容；构建用 `design/style-lab/.venv`。
