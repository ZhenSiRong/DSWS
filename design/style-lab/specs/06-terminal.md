# 风格 06 · 终端开发者志（Terminal Zine）

先读 `design/style-lab/BRIEF.md`，再执行本文件。目标：**一本给终端里长大的人看的开发者志**。等宽标题、`[01]` 章节号、深色代码岛、荧光绿/琥珀、终端式提示框；正文浅色可读，不要整本黑底。

## 视觉规则

- 网格：A4；上/下 18mm；左/右 18mm；正文单栏约 170mm；左上角 `user@dsws:~/book` 小条；正文浅色，代码/提示/封面深色。
- 字体：正文 `Noto Sans CJK SC` 9.4pt / 1.65 / #1B1F24；标题 `Noto Sans Mono CJK SC` 700，h1 22pt 前加绿色 `$` 或 `>`，h2 13pt，h3 10.8pt 用 sans 700；章节号 `[05]`/`[06]` 等宽绿。
- 色板：纸 #F5F5F0；墨 #1B1F24；次级 #5C6670；深色岛 #0E1116；绿 #00A86B；琥珀 #D97706；红 #C2410C；线 #D6D6CE。
- 表格：等宽表头、绿色 1pt 上规则、深色表头底 + 浅色字（可选）、0.3pt 行线；数字列等宽右对齐。
- 代码：深色 #0E1116 底、浅字 #E6E6E0、绿色提示符、8pt；左上角 `bash` / `python` / `ts` 小标签。
- 提示框：终端窗口样式——深色标题栏（三个圆点 + 标题）、深色正文、绿/琥珀标签；不要大圆角。
- 封面：深色 #0E1116 满版；顶部绿色 `user@dsws:~$`；主标题 40pt 等宽白；一行琥珀 `./read --part S5..S8`；中间终端输出式排版 + 绿色方块光标；底部 baseline/date 8pt 灰。
- 目录：`01  S5 · 安全边界 ........ 57` 等宽列表；h1 条目绿、h2 灰；顶部 `$ cat CONTENTS`。
- 图/表：图套终端窗口外框（标题栏 + 三点），图内容不变；图注等宽 7.8pt 灰；表题 `TABLE 3-1`。

## 验收

- 正文页必须真的套上终端风格，不能只有封面换皮；表格/代码可读。
- PDF 40–90 页；`style-notes.md` + 两张预览 PNG。
- 不要改章节内容；构建用 `design/style-lab/.venv`。
