# 风格 03 · 编辑杂志（Editorial）

先读 `design/style-lab/BRIEF.md`，再执行本文件。目标：**把设计图集做成一本有观点的杂志**。大字号衬线标题、非对称栏、首字下沉、拉引、整页图、每个部分一个主题色；不要像公司报告。**注意：只有 h1/部分 opener 可以整页留白，h2 不要强制另起一页**，否则会出现大量半空页。

## 视觉规则

- 网格：A4；上/下 20mm；左/右 18mm；8 栏非对称，主栏约 62%、侧栏约 30%；正文单栏，图注/拉引/边注可进侧栏。
- 字体：正文 `Noto Serif CJK SC` 9.9pt / 1.68；展示标题同族 900，h1 38–44pt、h2 20pt、h3 12pt 用 `Noto Sans CJK SC` 700；章节号巨大 72pt 衬线。
- 色板：纸 #FFFDF8；墨 #111；次级 #5B5B5B；线 #D9D3C7；S5 钴蓝 #1F4E9C、S6 锈红 #B24A2E、S7 森林绿 #2F5D46、S8 芥末 #C58B1B。
- 表格：表头强规则 + 浅 tint；表题主题色小标签；数字列 tabular。
- 代码：深墨 #151515 底 + 米色字 #F3EBDD；只让代码块深色，正文浅色。
- 拉引：24pt 衬线斜体、主题色、左侧 3pt 竖线；每章最多 1–2 处，从正文原句摘，不改写。
- 封面：满版深墨或深主题色；56pt 衬线白标题；巨大 `S5–S8` / `05—08` 背景（透明度 30%）；主题色横线；右下角一小块 SVG 图。要有杂志封面张力。
- 目录：杂志 Contents；左侧大标题，右侧分栏条目；部分用主题色数字 + 标题 + 一句短说明（只能从现有标题/正文提取）。
- 图/表：图可满版心/出血；图注侧栏或图下 8.2pt；表头可深色反白，但不要每张表都反白。
- 节奏：h1/部分 opener 才整页换气；h2 正常接排，前 8mm、后 3mm。

## 验收

- 不能出现连续半空页；正文页必须有足够内容。
- PDF 40–90 页；`style-notes.md` + 两张预览 PNG。
- 不要改章节内容；构建用 `design/style-lab/.venv`。
