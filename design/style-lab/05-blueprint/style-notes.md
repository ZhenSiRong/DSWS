# 05 · 工程蓝图 · 设计说明

**概念**：把书当成一套工程图纸。封面是图纸封面，正文页是带标题栏的图纸页；网格只出现在封面和章节 opener，避免长读疲劳。

**字体与网格**
- 正文 `Noto Sans CJK SC` 9.2pt / 1.68 / #10233F；标题 `Noto Sans Mono CJK SC` 700，h1 24pt、h2 13pt、h3 10.5pt。
- A4，上/下 18mm、左/右 16mm；正文页四边 0.4pt 蓝框，右上角 `SHEET [05]` 标题栏。
- 封面/章 opener 用 0.2pt 网格（10mm 间距）。

**色板**
- 纸 #F7FBFF；墨 #10233F；蓝图蓝 #0B3D91；辅助蓝 #2F6FB0；橙 #F28C28；线 #B8D0E8。
- 表格标题栏式表头，0.4pt 网格；代码白底 + 蓝色左边框 + `CODE` 标签。
- 图加蓝色外框与角标，图注等宽 `FIG. 07`。

**封面**
- 白底 + 蓝图网格；外框/内框；标题 40pt；橙色 1.5pt 线；右下角 `PROJECT / DWG NO. / BASELINE / SCALE / STATUS / SHEETS` 标题栏。
- 封面中央新增一张 `S0→S8 逐格新增不确定性与可停点` 矩阵图，用书里已有事实拼成，不是从现有 SVG 直接搬用。

**做了什么**
- 重写 `book.css`：图纸边框、标题栏、等宽标题、表格、代码、图框、页脚。
- 重写 `cover_html()`：网格、标题栏、矩阵图、尺寸标记。
- 修正章节号：`S5` 显示 `[05]`，不再用自增页码。

**已知限制**
- 封面矩阵图是新画的汇总图，不是现有 32 张图之一；正式采用时需要确认它是否进入图集编号。
- 正文页的蓝框 + 标题栏会压缩版心，长表格/长代码需要更多换页。
- 52 页，是三套里最紧凑的；图页留白较少。

**与另外 5 套的差异**
- 唯一的“图纸/标题栏/网格纸”语言；最像设计图集，也最容易被记住。

**图标**：Lucide inline SVG（circle-check / circle-alert / circle-help），3.2mm，颜色按本套色板；`vertical-align: -0.15em` 与正文基线对齐。
