# 04 · 日式留白 · 设计说明

**概念**：安静、精确、几乎全是空气。暖白纸、衬线正文、窄栏、极大页边、0.3pt 细线；标题用轻字重，封面只留一个小标题块和一条竖线。

**字体与网格**
- 正文 `Noto Serif CJK SC` 9.4pt / 1.95；标题 `Noto Sans CJK SC` 300/400，h1 18pt 字距 0.12em、h2 12.5pt。
- A4；上/下 30mm、左/右 28mm；正文约 130–140mm（每行 34–38 汉字）。
- 页眉 7.5pt 灰、页脚页码居中；章首页大量留白。

**色板**
- 纸 #FAFAF7；墨 #1C1C1C；次级 #6F6A62；线 #D8D4CC；强调靛蓝 #223A5E。
- 表格无底色/竖线；顶/底 0.4pt、行 0.25pt；代码浅纸色 + 0.3pt 细框。

**封面**
- 近空白；`D S W S` 小字；`DSWS` / `从零到一` 衬线标题 + 靛蓝竖线；副标题 9pt；底部 baseline/date。
- 目录大量留白，条目 8.5pt、行距 2.2。

**做了什么**
- 重写 `book.css`：窄栏、衬线正文、轻标题、细线表格、浅色代码块。
- 重写 `cover_html()`：极简封面、竖线、底部信息。
- 表 3-1 第一列加 `min-width`，避免“S5 安全边界”竖排。

**已知限制**
- 70 页，是六套里最长的；留白牺牲了信息密度。
- 正文 9.4pt + 1.95 行高，技术表格/代码页会显得偏空。
- 适合高端慢读或礼品书，不适合课堂快速查阅。

**与另外 5 套的差异**
- 唯一的“近空白封面 + 窄栏 + 轻字重”语言；最安静、最不工程化。

**图标**：Lucide inline SVG（circle-check / circle-alert / circle-help），3.2mm，颜色按本套色板；`vertical-align: -0.15em` 与正文基线对齐。
